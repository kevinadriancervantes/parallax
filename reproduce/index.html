Run one command

python reproducibility/verify_public_presentation_successor.py

Evidence custody

Checks the unchanged 1,600-row projection and the exact five-file SR-11R1 predecessor preserved at its historical route.

Campaign boundary

Checks that the governing 1,600-run SR-8R1 campaign and earlier 4,800-run Qwen stress campaign remain separate and never pooled.

Presentation integrity

Checks current public-state language, required caveats, internal links, and the August-versus-September submission distinction.

Privacy

Scans the physical release for private paths, credentials, authorization headers, private IPs, and machine identifiers.

What verification does not establish

Passing verifies custody and declared evidence roles. It does not rerun science, establish model competence, create a frontier-provider result, or submit a contest form.

Historical reproduction

The older August-23 and first Situation Room verifiers remain in GitHub for their original release packets. They are historical, not the current command.
