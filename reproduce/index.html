Run one command

python reproducibility/verify_policy_reader_presentation.py

Evidence custody

Checks the unchanged 1,600-row projection and the exact five-file SR-11R1 predecessor preserved in the repository.

Campaign boundary

Checks that the governing 1,600-run SR-8R1 campaign and earlier 4,800-run Qwen stress campaign remain separate and never pooled.

Presentation integrity

Checks the public explanation, required caveats, first-class navigation, and handoff to the technical repository.

Privacy

Scans the physical release for private paths, credentials, authorization headers, private IPs, and machine identifiers.

What verification does not establish

Passing verifies custody and declared evidence roles. It does not rerun science, establish model competence, or create a frontier-provider result.

Technical history

Earlier release verifiers, manifests, receipts, and frozen artifacts remain in GitHub as historical records. They are not the reader-facing route through this release.
