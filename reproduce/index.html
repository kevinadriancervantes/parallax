Raw README · Verifier source

Run one command

From the root of this public tree:

python reproducibility/verify_public_release.py

What it verifies

Predecessor receipts, release aggregate, manifest identity, payload hashes, physical allowlist, accepted Experiment 1 and 2 results, and Experiment 3 role separation.

What it does not need

No repository sibling, GPU, Ollama runtime, model weights, provider credentials, network access, funding, or model/provider calls.

Figures

Deterministic MATLAB figure data, source hashes, outputs, and rerun receipts are checked. MATLAB itself is not invoked by the public verifier.

Submission boundary

The proposal word limit, form mapping, unpublished deadline-clock status, canonical metadata, links, claim firewall, and contest-submission boundary are checked.

Privacy and public boundary

No raw local scientific rows, raw provider bodies, raw editorial-model output, credentials, account identifiers, or personal machine paths are present in the public tree. The release contains compact public summaries, provenance identities, figures, and reproducibility code.
