Measurement architecture

Ordered evidence, observable response, explicit unavailability.

Three fictional scenarios each contain five prospectively ordered evidence doses: STRONG_AGAINST, WEAK_AGAINST, BASELINE, WEAK_TOWARD, and STRONG_TOWARD. The substantive output remains three-category ordinal: LEANS_NOT_H, UNRESOLVED, or LEANS_H.

Behavioral refusal is a separate co-primary observable component, never placed on that ordinal scale. Measurement, transport, and unclassified unavailability are not imputed into answers. The eventual analysis must preserve a common eligible-unit denominator and a joint coherent identified set.

Three different validation layers

A

Synthetic shadow

Twelve known-ground-truth worlds exercised the full 556,200-coordinate geometry each. All 6,674,400 oracle comparisons matched. This validates software and analysis behavior, not model behavior.

B

Local Qwen2.5

4,800 real 7B/14B generations yielded 4,544 valid ordinal responses and 256 invalid enums. Dose paths were not uniformly monotone, and 17/60 nuisance comparisons were nonzero.

C

Provider paths

Six non-scientific Anthropic/Google probes qualified current transport and error handling. No scientific scenario was sent, and no provider result exists.

The local evidence is pathological by design

The reference study that has not run

The sealed reference plan separates two providers and 30 cells per provider, with N=9270 per cell, 278,100 calls per provider, 556,200 total scheduled calls, M=210, and global alpha=.05. It makes no full-joint power claim. Full execution funding is not secured and account capacity is unverified.

Current scientific boundary.

Experiment 3 has no Claude/Gemini scientific result, no confirmatory execution, and no experiment result assignment. Qwen does not substitute for the provider study.
