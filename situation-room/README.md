# Parallax Situation Room

This directory contains the current judge-facing public research presentation.
It reads the accepted SR-11R1 `data/data.json` projection without changing its
observations, classifications, contrasts, exclusions, or claim boundaries.

The five exact pre-publication SR-11R1 artifacts are preserved under
[`provenance/sr11r1-frozen/`](provenance/sr11r1-frozen/). Their original status
labels remain untouched as historical custody evidence. Current publication is
established by the additive public-presentation release receipt.

No model or provider call is required to view or verify this module.
